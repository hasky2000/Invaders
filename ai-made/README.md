# Space Invaders

Python と pygame で作った、800×600 のクラシックなインベーダーゲームです。
画像・音声ファイルのダウンロードは不要です。

## 起動

プロジェクトのルートディレクトリから実行してください。

```bash
venv/bin/python -m pip install -r ai-made/requirements.txt
venv/bin/python ai-made/main.py
```

別の Python 環境を使う場合は、`venv/bin/python` をその環境の `python` に置き換えてください。

## 操作

| キー | 操作 |
| --- | --- |
| Enter / Space | ゲーム開始・ゲームオーバー後の再挑戦 |
| ← → / A D | 自機を左右に移動 |
| Space（長押し可） | 弾を発射（画面内に最大2発） |
| P | 一時停止・再開 |
| Esc | 終了 |

残機は3機。敵を全滅させると次のウェーブへ進みます。
敵は数が減るほど速くなり、画面端で折り返して下降します。
敵に自機の高さまで侵攻されるか、残機がなくなるとゲームオーバーです。
防壁は双方の弾で削れ、次のウェーブにも損傷が引き継がれます。
被弾後は短時間無敵になり、ウィンドウがフォーカスを失うと自動で一時停止します。

得点は上段から30・20・20・10・10点。時々通過するUFOは50〜300点です。
ハイスコアはアプリの起動中のみ保持します。

## コード

`main.py` に描画・入力・ゲーム進行をまとめています。
`Game` がゲーム全体、`Shield` が防壁の形状と破壊、
`Alien`・`Bullet`・`Popup` が各要素のデータを担当します。
ドット絵はファイル冒頭のパターン定義から描画しています。
文字は `pixel_font.py` のドットフォントで描画するため、システムフォントも不要です。
