# Space Invaders

Python と pygame で作った、800×600 のクラシックなインベーダーゲームです。
内部解像度は800×600で固定し、表示だけをドットの輪郭をぼかさず拡大します。
実行ライブラリにはpygame互換のpygame-ceを使います。
画像・音声ファイルのダウンロードは不要です。仮SEは起動時に電子音として生成します。
淡い天の川銀河のピクセルアートを同梱し、背景として描画しています。
背景の明るさは原画の約90%にしています。

## 起動

Linux / WSLでは、プロジェクトのルートディレクトリから実行してください。
仮想環境がまだない場合は、最初に作成します。

```bash
python3 -m venv venv
venv/bin/python -m pip install -r requirements.txt
venv/bin/python main.py
```

仮想環境を有効化して実行することもできます。

```bash
source venv/bin/activate
python main.py
```

別の Python 環境を使う場合は、`venv/bin/python` をその環境の `python` に置き換えてください。
既存環境にpygameが入っている場合は、先に `venv/bin/python -m pip uninstall pygame` で削除してから依存関係をインストールしてください。同じ環境にpygameとpygame-ceを混在させないでください。

起動時は画面に収まる最大2倍のウィンドウで表示します（1倍・1.5倍・2倍から自動選択）。
ウィンドウの端をドラッグしてさらに拡大・縮小でき、F11で全画面とウィンドウを切り替えられます。
縦横比は4:3を維持し、余った部分は黒帯になります。移動速度や当たり判定は表示サイズで変わりません。

### 日本語フォント

チュートリアルなどの日本語表示には、`fonts/DotGothic16-Regular.ttf` を使います。
システムへの日本語フォントのインストールは不要です。フォントのライセンスは `fonts/OFL.txt` にあります。
日本語は24pxのフォント、タイトルと既存HUDの英数字は従来のドットフォントで表示します。

## タイトルとチュートリアル

起動すると、背景に「SPACE INVADERS」と「PRESS ANY KEY」だけを表示します。
通常のキーを押すとphase0のチュートリアルに入り、次の順に練習します。

1. ← → または A・D で、左右それぞれ24px以上移動する。
2. Spaceキーで実際に弾を1発撃つ。長押しで連射できることも説明する。
3. 敵を1機撃墜する。落下した敵との衝突による連鎖も説明する。
4. Bキー（パッドは○／Bボタン）でボムを使い、2行×2列の敵をまとめて倒す。
5. 練習用の敵弾を受け、ハートが1つ減ることと約1.8秒の無敵時間を確認する。
6. 本編が全3フェーズであること、全滅で次へ進むこと、EXTRAの突入条件を確認する。

撃墜・ボム練習ではphase1と同じ移動・下降・砲撃を行います。防壁・UFOは登場しません。
各課題は残機5から始まり、残機切れや敵の侵攻時には現在の課題だけをやり直します。
ボムはボム練習だけで使え、外した場合は爆発後に補充されます。本編の使用回数は各フェーズ1・2・3発です。
被弾練習では移動せずに待つと弾が当たります。ハートが0になるとゲームオーバーになることも説明します。
最後の説明では、phase3を残機3以上でクリアするとEXTRAへ進むことを案内します。
Enter／Space（パッドは射撃ボタン／START）で確認し、0.8秒後にphase1から本編を開始します。
説明を読めるよう、最後の画面へ入ってから最初の1秒間は確認操作を受け付けません。
練習の得点はハイスコアに反映せず、本編はスコア0・残機5・ボム1・新品の防壁で始まります。
練習中の失敗はプレイヤーの成績にも記録しません。

チュートリアル中は、Tabなど操作に使わない同じキーを2秒長押しするとスキップしてphase1へ進みます。
移動・射撃・ボム・精密移動・メニュー・各種切替の操作キーと、パッドの操作ボタンはスキップ対象から除きます。
キーごとに計測し、別のキーへ切り替えても時間を合算しません。
タイトルで押したキーは一度離してから使えます。フォーカス喪失時は押下状態をリセットします。
Esc・F11はそれぞれの機能を優先し、開始・スキップ操作から除きます。F2はタイトルではデバッグ画面を開きます。

本編はphase1→2→3へ進みます。ゲームオーバー／クリア後の再挑戦は、チュートリアルを省略してphase1から開始します。

### テスト用のフェーズ選択

タイトル・終了画面でF2を押すと、デバッグ画面を開きます。
1・2・3キーで通常フェーズ、4キーでEXTRAを選び、Enter／Spaceで直接開始できます。
初期選択はphase1です。選んだフェーズから残機5・スコア0・規定数のボムで開始します。
F2をもう一度押すとタイトルへ戻ります。再挑戦で別のフェーズを使う場合も、F2から選び直してください。

## コントローラー

接続中のPS3コントローラーを自動認識します。ゲームを再起動して使用してください。
SDLが対応するゲームパッドを対象とし、キーボードとの併用や起動後の接続・再接続にも対応します。

| PS3の操作 | 動作 |
| --- | --- |
| 左スティック／十字キー | 移動。通常フェーズは左右、EXTRAでは上下左右・斜め |
| × | 射撃（長押し）／タイトル・終了画面で決定・再挑戦 |
| ○ | ボム（押したときに1発） |
| L1／R1 | EXTRAの精密移動（押している間） |
| START | 開始／一時停止・再開 |
| SELECT | SEのオン／オフ |
| 十字キー左右／左スティック左右（デバッグ画面） | 開始フェーズを選択。EXTRAも選べます |

左スティックは倒す量に応じて速度が変わり、中央付近の小さなズレは無視します。
EXTRAの自動射撃はそのまま使えます。プレイ中に接続が切れると、自動で一時停止します。
接続・再接続時に押されていたボタンは、新しい押下として扱いません。
開始待ちや一時停止から持ち越した○ボタンの入力も、一度離してから押し直すまでボムを発射しません。
タイトルでは×／STARTでチュートリアルを開始し、開始時のボタンは一度離してから操作します。
接続中はチュートリアルにパッド操作の案内を表示します。
Xbox型のコントローラーでは×相当がA、○相当がB、L1／R1相当がLB／RBです。

残機は5機。敵は1フェーズにつき60体で、全滅させると次へ進みます。
画面左下には、残機の数だけピンクのハートアイコンを表示します。被弾で残機が減るとハートも減ります。
フェーズ3を残機3以上でクリアするとEXTRAへ進みます。残機1〜2では「ALL CLEAR!」を表示して終了します。
開始待ちは0.7秒、クリア後の待ちは0.8秒で、短いテンポで遊べます。
最後の敵の落下・爆発演出が終わってから、クリア後の待ち時間に入ります。

## EXTRAステージ

フェーズ3クリア時の残機が3以上で突入します。ゲームオーバーからは突入しません。
スコアは引き継ぎ、残機を5に戻し、防壁・前ステージの弾と演出を取り除きます。
ボムは3発へ補充し、6×6pxの被弾判定を維持します。
EXTRAではSpaceを押さなくても常時自動射撃します。フェーズ3と同じく左右の砲から0.13秒おきに交互発射し、各砲は0.26秒間隔、画面内の自機弾は最大4発です。
背景の天の川はEXTRA専用の暗い赤基調になり、通常フェーズへ戻ると元の色に戻ります。
EXTRAでは通常移動を180px/秒に下げ、左右どちらかのShiftを押しながら移動すると90px/秒で精密に動けます。
WASDまたは矢印キーで上下左右・斜めに移動でき、斜めでも速度は変わりません。HUDと画面下部の表示を除いた範囲で動けます。

中央に160×128pxの大型ボス、周囲に10機の取り巻きが出現します。
ボスはインペリアル・スターデストロイヤー風の、灰色の楔形船体・段状甲板・艦橋・2つの球形センサーを持つドット絵です。
ボスのHPは240で、画面上部に数値と体力バーを表示します。
通常弾は1、ボムは15、落下する取り巻きの衝突は5のダメージを与えます。爆発の見た目にはダメージ判定がありません。
ボスは左右2か所の砲口から、12回の一斉射撃ごとに切り替わる高密度の幾何学的弾幕を放ちます。
ROSETTEは逆回転する2つの円形弾幕を32発ずつ約0.458秒間隔で重ね、花形の模様と動く隙間を作ります。
CROSSは内側へ向けて揺れる2つの扇形弾幕を34発ずつ約0.566秒間隔で撃ち、交差する格子を作ります。
HELIXは逆回転する2組の8方向弾を16発ずつ約0.153秒間隔で放ち、二重の螺旋を作ります。
ピンクの丸弾が等速115.2px/秒で広がり、発射後に自機を追尾しません。画面上部に現在の弾幕パターンも表示します。
取り巻きの通常弾は最大14発、EXTRA全体の敵弾は最大221発です。ボスは模様が欠けないよう一斉射撃分の空きを待ちます。

取り巻きのうち2機は、赤い装甲と太い砲身を持つビーム砲台です。
それぞれタイミングをずらし、2秒間の赤いレーザー予告のあと、幅48pxのビームを0.45秒間放ちます。
予告はビームと同じ太さの半透明の赤い帯で、予告開始時の自機の中心へ向けて照準を固定します。
赤い背景でも見える明るさで、弾や自機の下に描画します。右上の「LASER」には発射までの残り秒数を表示します。
砲台の位置とレーザーの向きは、予告開始から発射終了まで動きません。次の予告を始めるときに改めて狙い直します。
ビームは砲台から1800px/秒で伸びるため、発射後に横へ動いて回避できます。
判定は斜めのビームの幅48pxと実際に伸びた部分に沿い、外接する矩形の空白には当たりません。
ビームが自機中央の当たり判定に触れると、残機数・通常被弾後の無敵時間にかかわらず即ゲームオーバーです。
発射元の砲台を撃墜すると、予告・発射中のビームも止まります。

取り巻きだけを全滅させても終了しません。ボスのHPを0にすると取り巻きも崩壊し、演出のあと「EXTRA CLEAR!」でゲームクリアです。

| フェーズ | 敵の動き | ボム |
| --- | --- | --- |
| 1 | 密集した千鳥配置（横36px・縦32px間隔）。次の行の複数機を巻き込みやすい隊列で、画面端では全体が折り返して下降 | 1発 |
| 2 | フェーズ1と同じ全体移動に、行ごとの小さな左右の揺れ（±12px）を重ねる。6pxずつ段階的に揺れ、折り返し・下降は全体で行う | 2発 |
| 3 | 15機ずつ4小隊に分かれて移動。隊列移動と段階的な行の揺れに、小隊ごとの周期をずらした左右・上下動を重ねる | 3発 |

フェーズ3の各小隊は3行×5列で、小隊内は横36px・縦30px間隔です。
上下の小隊には通常92pxの隙間があり、普段の落下では届きません。
上側の小隊は下へ、下側の小隊は上へ最大24px動いて接近し、元の位置へ戻ります。
接近したときに、落下機が別の小隊へ届く時間が生まれます。
フェーズ3の配置は以前より24px上へ移し、下側の小隊が上下動で自機側へ張り出さないようにしています。
画面端での下降量も22pxから12pxへ減らし、自機との距離に余裕を持たせています。
小隊をまたぐ連鎖は実際の接触で判定するため、接近するタイミングを狙うと大きな連鎖を作れます。
左右動は最大36px、行の揺れは±18pxで、どちらも段階的に動きます。
6秒ごとのSWAY→RUSH→WEAVEによるテンポの変化も維持しています。

敵の砲撃もフェーズごとに強くなります。各列の最下段の敵から発射します。

| フェーズ | 発射間隔 | 同時発射 | 弾速 | 敵弾の上限 |
| --- | --- | --- | --- | --- |
| 1 | 0.80〜1.25秒 | 1機 | 180px/秒 | 4発 |
| 2 | 0.52〜0.84秒 | 2機 | 180px/秒 | 8発 |
| 3 | 0.30〜0.50秒 | 最大3機（特殊敵は3発ずつ） | 通常180px/秒・特殊108px/秒 | 14発 |

フェーズ3には、金色の機体に白い角飾りと紫のコアを持つ特殊敵が12体出現します。
通常敵は真下への直進弾、特殊敵は横にうねりながら3方向へ広がる紫の丸弾を撃ちます。
特殊弾は下方向108px/秒でゆっくり進み、左右の揺れ幅は22pxです。
弾の軌道は発射時に決まり、自機の位置に応じた狙い撃ちや追尾は行いません。
特殊弾にも防壁・自機との当たり判定があり、ボムで消せます。
特殊敵は砲撃タイミング3回分の攻撃ターンのあと、2回分休みます。この5ターンを繰り返します。
休止中は特殊敵の色が暗くなり、画面上部に「SPECIAL REST」と表示します。
休止中の特殊敵は直進弾も撃ちません。通常敵の砲撃は続きます。

残り8機以上では通常どおり、7機からは全フェーズで砲撃を徐々に緩和します。
敵が1機減るごとに発射レートを線形に下げ、最後の1機では1.8〜2.4秒おきに発射します。
緩和は次の発射までの残り時間にも反映します。撃墜による敵弾の一斉消去や、残り3機での特別処理はありません。
弾速・弾の軌道・同時発射数・画面内の弾数上限は敵数によって変えません。
通常弾は全フェーズ共通で180px/秒です。特殊敵は108px/秒の曲線弾を維持し、3ターン攻撃・2ターン休止も続けます。

現在の移動パターンは画面下部に表示します。
自機の見た目は全フェーズで単装のままです。
自機の移動速度は通常フェーズでは260px/秒、EXTRAでは180px/秒（Shift中は90px/秒）です。
通常フェーズとチュートリアルの被弾判定は、自機画像の不透明な部分に沿います。翼や機首に弾が触れると被弾し、画像内の透明な余白では被弾しません。
EXTRAでは機体中央の6×6pxの正方形を被弾判定とし、暗い縁取りを付けた不透明の白で表示します。
EXTRAの判定表示は弾幕の手前に描き、被弾で機体が点滅している間も消えません。
フェーズ1・2の発射間隔は0.26秒。フェーズ3は左右の砲から0.13秒おきに1発ずつ交互に撃ちます。
各砲の発射間隔は0.26秒のままで、2門合わせた発射レートが2倍になります。
いずれも画面内の弾数が上限に達している間は次の発射を待ちます。
敵は数が減るほど緩やかに速くなります。撃破割合による移動間隔の短縮は最大0.128秒、
フェーズごとの短縮は0.015秒で、基本の移動間隔の下限は0.22秒です。
フェーズ3はさらに隊列移動を1.12〜1.45倍、行の横揺れを1.35〜2.2倍に速めます。
敵に自機の高さまで侵攻されるか、残機がなくなるとゲームオーバーです。
防壁は双方の弾で削れ、次のフェーズにも損傷が引き継がれます。
被弾後は短時間無敵になり、ウィンドウがフォーカスを失うと自動で一時停止します。

ボムは自機の位置から上へ進み、飛行時間に応じて390px/秒から毎秒180px/秒ずつ減速します。
最低速度は90px/秒で、止まらず進み、敵に当たるか画面上部に達すると爆発します。
爆発地点から半径110pxに触れる敵・UFOを倒し、範囲内の敵弾も消します。
ボムの爆発は、敵機の撃墜爆発と共通の火球・衝撃波・煙・破片を約2倍の大きさで描画します。
爆風の見た目による追加ダメージはなく、攻撃範囲は半径110pxのままです。
防壁は通過し、自機や防壁にはダメージを与えません。ボム撃破も通常どおり得点になります。
残数は画面下部に表示され、各フェーズ開始時に規定数へ補充されます（持ち越し・上乗せなし）。

得点は上段から30・20・20・10・10・10点。時々通過するUFOは50〜300点です。
ハイスコアはアプリの起動中のみ保持します。

敵は撃墜されると煙と火花を引きながら傾いて短時間落下し、火球と衝撃波を伴って爆発します。
爆発には多段の火球、十字の閃光、二重の衝撃波、遅れて飛び散る火花と破片を重ねています。
爆発後も煙が広がって上昇し、飛び散った火花が消えていきます。
落下中の機体に衝突した敵も撃墜され、さらに落下して連鎖します。
敵機の爆発は演出のみで、ダメージや範囲攻撃の判定はありません。
通常弾・ボム・衝突のいずれで倒しても、撃墜時に一度だけ得点が加算されます。

衝突による連鎖が起きると、画面上部に「02 COMBO!」のように表示します。
最初の撃墜を含め、同じ連鎖で撃墜した機数を合計します。別々の射撃の連鎖は合算しません。
ボムでは同時撃墜を同じ連鎖として扱いますが、衝突が起きるまではコンボ表示を出しません。
連鎖が伸びるたびに表示を更新し、約2秒後に消えます。同時進行では表示中の大きいコンボを優先します。

## 仮SE

射撃、敵の砲撃、撃墜、爆発、ボム発射・爆発、被弾、コンボ、フェーズクリア・ゲームクリアに電子音を付けています。
Mキーでミュートでき、一時停止中は再生中のSEも停止状態になります。
pygame-ceに含まれるpygame.mixerで再生します。
音声デバイスや必要なライブラリが使えない場合は、音を無効にしてゲームを続行します。

## コード

`main.py` に描画・入力・ゲーム進行をまとめています。
`Game` がゲーム全体、`Shield` が防壁の形状と破壊、
`Alien`・`Bullet`・`Bomb`・`Blast`・`Popup` が各要素のデータを担当します。
`FallingAlien` は撃墜後の落下と姿勢、`Explosion` は当たり判定のない爆発演出を担当します。
フェーズ2・3の行ごとの揺れは `row_offsets`、フェーズ3の小隊の動きは `squad_offsets` で管理します。
`effects.py` は煙・火花の生成、更新、描画を担当し、当たり判定には関与しません。
`KillChain` が連鎖の起点と撃墜数を管理します。
`sound.py` がSEの合成・再生を担当します。
`controls.py` がゲームパッドの認識、スティックの中央補正、ボタン押下、再接続を担当します。
`pixel_display.py` が800×600の描画面を拡大し、リサイズ・縦横比・全画面切り替えを扱います。
`extra_stage.py` がボスとビーム砲台の状態、周回移動、ドット絵とビーム描画を担当します。
背景の原画・実行用画像・生成プロンプトは `assets/` に保存しています。
背景画像は起動時に一度だけ加工し、プレイ中はキャッシュした画像を描画します。
ドット絵はファイル冒頭のパターン定義から描画しています。
英数字の文字は `pixel_font.py` のドットフォント、日本語の説明は `fonts/DotGothic16-Regular.ttf` で描画します。
`tutorial.py` がチュートリアルの課題・達成状況・キーごとの長押し時間を管理します。
